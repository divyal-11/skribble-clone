Live Room Lifecycle Sequence (Host ➔ Join ➔ Leave)

Step-by-step trace of WebSocket packet exchanges and Redis mutations between two browser tabs.

sequenceDiagram autonumber actor Alice as 👩 Player A (Alice) actor Bob as 👨 Player B (Bob) participant Client as 🖥️ Next.js Client participant Server as ⚙️ Socket.IO Server participant Redis as 💾 Redis Database Note over Alice, Redis: PHASE 1: Room Creation & Host Initialization Alice->>Client: Enters "Alice", clicks "Create Room" Client->>Server: emit("joinRoom", { roomId: "XK92DF", playerName: "Alice" }) Server->>Redis: HGETALL room:XK92DF (Check existence) Redis-->>Server: null (New Room) Server->>Redis: HSET room:XK92DF hostId "alice-uuid", status "LOBBY" Server->>Redis: HSET room:XK92DF:players "alice-uuid" JSON({ isHost: true }) Server->>Redis: EXPIRE 7200 seconds Server->>Server: socket.join("XK92DF") Server-->>Alice: emit("joinedRoom", { room, players: [Alice] }) Note over Alice: Alice enters Lobby view as 👑 Host Note over Bob, Redis: PHASE 2: Player B Joins the Live Room Bob->>Client: Enters "Bob", inputs "XK92DF", clicks "Join" Client->>Server: emit("joinRoom", { roomId: "XK92DF", playerName: "Bob" }) Server->>Redis: HGETALL room:XK92DF (Found! Host is Alice) Server->>Redis: HSET room:XK92DF:players "bob-uuid" JSON({ isHost: false }) Server->>Server: socket.join("XK92DF") Server-->>Bob: emit("joinedRoom", { room, players: [Alice, Bob] }) Server--)Alice: socket.to("XK92DF").emit("playerJoined", Bob) Note over Alice, Bob: Both Alice and Bob now see each other live in the roster! Note over Bob, Redis: PHASE 3: Player B Leaves Room Bob->>Client: Clicks "Leave Room" Client->>Server: emit("leaveRoom", { roomId: "XK92DF" }) Server->>Redis: HDEL room:XK92DF:players "bob-uuid" Server->>Server: socket.leave("XK92DF") Server--)Alice: socket.to("XK92DF").emit("playerLeft", { playerId: "bob-uuid" }) Note over Alice: Alice sees toast: "Bob left the room" and roster updates!
