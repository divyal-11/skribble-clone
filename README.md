# skribble-clone

A simple multiplayer Skribbl.io clone built to learn and explore WebSockets, real-time synchronization, and event-driven communication.

Based on and referencing the architecture from [Building a Skribbl.io Clone: From Concept to Completion](https://medium.com/@divyanshulohani/building-a-skribbl-io-clone-from-concept-to-completion-2b60ca98f466).

See [skribbl-clone-blueprint.md](./skribbl-clone-blueprint.md) for the full architecture design and implementation plan.
